# macos-shell Specification

## Purpose
定义应用在 macOS 上的窗口与常驻行为：一个主窗口、菜单栏入口、全局快捷键唤出，以及关闭窗口不退出程序的完整显隐语义。

## Requirements

### Requirement: 单主窗口

应用 MUST 只维护一个主笔记窗口；主窗口默认尺寸 1100×720，最小尺寸 760×480，MUST 居中显示且 MUST 带原生窗口控制按钮。全局快捷键、菜单栏与界面内部操作 MUST 复用该窗口，MUST NOT 创建新窗口实例。

#### Scenario: 连按快捷键只有一个窗口
- **WHEN** 连续 100 次触发全局快捷键或菜单栏切换
- **THEN** 系统中始终只存在一个笔记窗口，无重复实例或残留幽灵窗口

#### Scenario: 尺寸受最小约束
- **WHEN** 用户把窗口缩小到极限
- **THEN** 宽高不低于 760×480，布局不出现内容溢出或控件不可达

### Requirement: 关闭即隐藏

点击窗口关闭按钮 MUST 隐藏窗口而不退出进程，MUST 保留 WebView 与未保存状态；只有经确认的退出动作 MUST 结束进程。

#### Scenario: 关闭按钮隐藏
- **WHEN** 用户点击关闭按钮
- **THEN** 窗口消失但应用仍在菜单栏运行，再次唤出时内容与滚动位置保持

### Requirement: 启动不显示主窗口

应用 MUST 以隐藏状态启动：进程启动、菜单栏图标出现、数据库与前端就绪后 MUST NOT 自动显示主窗口。用户 MUST 能通过菜单栏或全局快捷键唤出。首次运行的说明 MUST 从菜单栏侧（一次性提示或引导）给出，MUST NOT 依赖自动弹出主窗口。

#### Scenario: 冷启动保持隐藏
- **WHEN** 用户在 Finder 或登录项中启动应用并等待前端就绪
- **THEN** 主窗口始终不出现，菜单栏出现图标，进程在后台待命，按快捷键即可唤出

#### Scenario: 首次启动仍可发现
- **WHEN** 全新安装后首次启动且主窗口保持隐藏
- **THEN** 用户能从菜单栏看到应用并唤出窗口，或收到一次性的快捷键说明，不会误以为应用没启动

### Requirement: 退出确认

通过菜单栏「退出」、`Command+Q` 或系统退出动作请求退出时，系统 MUST 先 flush 未保存编辑，再显示确认对话框。用户取消 MUST 保持应用运行且窗口状态不变；确认后 MUST 结束进程。存在未保存内容或保存失败时 MUST 在对话框中说明，保存失败 MUST NOT 静默退出。

#### Scenario: 取消退出
- **WHEN** 用户触发退出并在确认对话框中取消
- **THEN** 进程继续运行，窗口显隐状态与编辑内容保持原状

#### Scenario: 确认退出
- **WHEN** 用户触发退出并确认
- **THEN** 未保存编辑先落盘，随后进程结束，菜单栏图标消失

#### Scenario: 未保存内容提示
- **WHEN** 存在未保存编辑时触发退出
- **THEN** 确认对话框说明仍有未保存内容；若保存失败则停留在对话框并提示错误，不结束进程

### Requirement: 全局快捷键唤出

系统 MUST 注册默认全局快捷键 `CommandOrControl+Shift+D` 用于切换主窗口显隐；注册失败 MUST NOT 阻断启动，MUST 以可见提示告知快捷键不可用。快捷键 MUST 可在设置中修改，且 MUST 拒绝已被系统占用的组合。

#### Scenario: 隐藏时唤出
- **WHEN** 窗口处于隐藏状态且用户按下快捷键
- **THEN** 窗口显示、居中、置于最前并获得键盘焦点

#### Scenario: 可见时隐藏
- **WHEN** 窗口可见且用户按下快捷键
- **THEN** 窗口隐藏，应用进程继续运行

#### Scenario: 快捷键冲突
- **WHEN** 用户设置的组合已被其他应用占用
- **THEN** 设置界面提示冲突并要求重新输入，旧快捷键保持有效

### Requirement: 显示时定位与置顶

每次显示 MUST 恢复上次的窗口尺寸、按当前鼠标所在显示器居中并限制在可见区域内，MUST 在显示期间保持置顶，MUST 在隐藏时取消置顶。MUST NOT 保存或恢复窗口坐标。

#### Scenario: 鼠标在副屏
- **WHEN** 鼠标位于副显示器且用户唤出窗口
- **THEN** 窗口出现在该显示器中央而非主屏

#### Scenario: 显示器断开
- **WHEN** 上次使用的副屏被拔掉后再唤出窗口
- **THEN** 窗口出现在现存显示器可见范围内，不落在屏幕外

#### Scenario: 置顶仅在显示时生效
- **WHEN** 窗口隐藏后用户切换到其他应用
- **THEN** 其他应用窗口正常获得焦点，不被隐藏窗口抢占

### Requirement: 菜单栏常驻

应用 MUST 提供菜单栏图标与菜单，至少包含：显示/隐藏窗口、新建笔记、打开笔记库、设置、开机启动开关、退出。菜单项 MUST 与界面内同名操作使用同一业务路径。

#### Scenario: 菜单新建笔记
- **WHEN** 用户在菜单栏选择「新建笔记」
- **THEN** 窗口显示并进入新建笔记的编辑状态，聚焦标题

#### Scenario: 菜单栏显示品牌标识
- **WHEN** 应用运行于菜单栏
- **THEN** 显示品牌 logo（蓝色圆角方块标记），高度约 18pt、按等比缩放，在深浅色菜单栏下都能辨认

### Requirement: 单实例

应用 MUST 保证仅有一个进程实例；重复启动 MUST 唤出已运行实例的主窗口而 MUST NOT 新开进程。

#### Scenario: 重复打开应用
- **WHEN** 应用已在运行（窗口隐藏）时用户从 Finder 再次打开
- **THEN** 已运行实例的窗口显示并聚焦，不出现第二个进程

### Requirement: 开机启动

设置 MUST 提供可开关的登录时启动项，且 MUST 反映系统实际授权状态。

#### Scenario: 开启后状态持久
- **WHEN** 用户开启开机启动并重启系统
- **THEN** 应用在登录后自动运行于菜单栏，主窗口默认隐藏

### Requirement: 编辑区宽度可控

左栏宽度 MUST 可通过拖拽调整，范围 MUST 限制在 220–420px 且不超过窗口宽度的合理比例；宽度 MUST 在下次启动时恢复。

#### Scenario: 拖拽调宽并记住
- **WHEN** 用户把左栏拖到 380px 后重启应用
- **THEN** 左栏宽度仍为 380px

#### Scenario: 窄窗口下不挤压内容区
- **WHEN** 窗口缩小到最小尺寸且左栏为 420px
- **THEN** 左栏被限制到合法上限，右侧内容区仍可使用
