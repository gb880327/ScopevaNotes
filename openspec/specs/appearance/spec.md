# appearance Specification

## Purpose
控制界面视觉表现：深浅色模式与跟随系统、强调色、编辑器字号，并在任何背景下保证文字对比度可读；偏好设置与笔记数据分离存放，跨启动持久且损坏时不阻断启动。

## Requirements

### Requirement: 主题模式

外观设置 MUST 提供浅色、深色、跟随系统三种模式；跟随系统时 MUST 在系统外观变化后即时切换，无需重启。切换 MUST 对左栏、内容区、Markdown 预览与代码块同时生效。

#### Scenario: 跟随系统即时生效
- **WHEN** 主题为「跟随系统」且用户在系统设置中切换到深色
- **THEN** 应用界面即时变为深色配色，文字对比度仍满足可读性

#### Scenario: 编辑器与预览同步换色
- **WHEN** 用户从浅色切到深色（或反向），编辑器里已有打开的笔记
- **THEN** CodeMirror 的正文、标题、链接、引用、列表标记与代码块高亮同时换色，笔记内容与光标位置不变

#### Scenario: 强制浅色
- **WHEN** 用户显式选择浅色而系统为深色
- **THEN** 应用保持浅色，不随系统变化

### Requirement: 强调色

设置 MUST 提供至少 5 种强调色，选中项 MUST 应用于选中态、链接、开关与聚焦描边等交互元素，且 MUST 在深浅色模式下均保持可读对比度。强调色用于文字或按钮填充时 MUST 使用可读变体（`--accent-text`）而不是品牌填充色（`--accent`），使文字对背景 ≥ 4.5:1。

#### Scenario: 强调色只改变交互元素
- **WHEN** 用户把强调色从蓝改为橙
- **THEN** 选中态与按钮强调色变化，正文阅读区背景与字号不变

#### Scenario: 五种强调色都满足文字对比度
- **WHEN** 依次选用蓝、紫、绿、橙、石墨，并在浅色与深色间切换
- **THEN** 链接、恢复链接、收藏标记与主按钮文字在页面底、侧栏底、抬升底、输入框底、选中底与强调色浅底上都 ≥ 4.5:1

### Requirement: 文字对比度

界面中所有文字 MUST 对实际渲染背景满足 WCAG AA 对比度（普通文字 ≥ 4.5:1，≥18.66px 或 ≥14px 加粗的大字 ≥ 3:1）。半透明背景 MUST 先与页面底色合成后再计算。该约束 MUST 有自动化测试守着，取值漂移时测试失败。

#### Scenario: 次要文字在选中行上仍可读
- **WHEN** 列表里某一笔记被选中，其标题、摘要与时间戳都显示在选中底色上
- **THEN** 三者的对比度都 ≥ 4.5:1，选中态不牺牲次要文字可读性

#### Scenario: 代码块文字
- **WHEN** 预览中渲染带语法高亮的代码块
- **THEN** 每个 token 颜色对其代码块底色 ≥ 4.5:1，浅色与深色主题分别成立

### Requirement: 编辑器字号

设置 MUST 允许调整编辑器与预览代码块字号，范围 MUST 限制在可读区间（12–24px），修改 MUST 立即应用于当前打开的编辑器。

#### Scenario: 字号即时生效
- **WHEN** 用户在设置中把字号从 15px 调到 20px
- **THEN** 当前编辑区字号立即变为 20px，无需重新打开笔记

### Requirement: 偏好持久化与隔离

界面偏好 MUST 持久化到应用配置（Tauri Store），MUST NOT 写入笔记数据库；MUST 在启动时恢复，且存储不可用时 MUST 回退到默认值而不是启动失败。

#### Scenario: 重启恢复
- **WHEN** 用户设置深色 + 橙色 + 20px 后重启应用
- **THEN** 三项设置全部恢复

#### Scenario: 配置损坏不阻断启动
- **WHEN** 偏好存储内容损坏或不可读
- **THEN** 应用以默认主题与字号启动，笔记数据不受影响
