## MODIFIED Requirements

### Requirement: 速记面板的定位

面板显示时 MUST 以菜单栏图标的位置为锚点定位（图标下方、水平居中对齐图标）并 MUST 限制在图标所在显示器的可见区域内，MUST 处理多显示器与不同缩放比例。MUST NOT 保存或恢复面板坐标。

面板尺寸 MUST 在下次显示时恢复，且该尺寸 MUST 跨进程重启持久化（保存到应用配置）；读取时 MUST 做合法性收敛：小于最小尺寸（360×220）的值 MUST 提升到最小尺寸，超出当前显示器可见区域的值 MUST 收进可见区域。配置不可用时 MUST 回退到默认尺寸（480×320）继续工作。

当菜单栏处于自动隐藏状态（即当前处于全屏 Space）时，面板 MUST 改为贴住所在显示器顶边，MUST NOT 在滑走的菜单栏位置留下空隙。

#### Scenario: 副屏图标在副屏弹出
- **WHEN** 菜单栏图标位于副显示器且用户点击它
- **THEN** 面板出现在该显示器上、贴着菜单栏而不越出屏幕

#### Scenario: 显示器断开后仍在可见区域
- **WHEN** 上次显示面板的显示器被拔掉后再唤出面板
- **THEN** 面板出现在现存显示器的可见区域内

#### Scenario: 调整面板尺寸后重启仍是上次的尺寸
- **WHEN** 用户把面板拖到 640×420，然后隐藏面板并退出应用，再重新启动并点击菜单栏图标
- **THEN** 面板以 640×420 显示，而不是默认的 480×320

#### Scenario: 保存的面板尺寸小于最小尺寸
- **WHEN** 配置里的面板尺寸被写成 200×120（低于最小尺寸）
- **THEN** 面板以 360×220 显示，内容不被裁掉

## ADDED Requirements

### Requirement: 速记面板打开时的插入点

面板每次显示时，编辑区的插入点 MUST 落在当前速记正文的最开头，且视图 MUST 滚到顶部，使用户无需滚动就能看到第一行。该行为 MUST NOT 依赖用户手动点击或移动光标。

切换速记、新建速记、重命名之后重新获得焦点时 MUST 同样落在最开头。空正文时该要求自然满足，MUST NOT 因此产生额外行为（例如插入占位文本）。

#### Scenario: 打开较长的速记
- **WHEN** 当前速记正文有 200 行，用户隐藏面板后再次点击菜单栏图标唤出面板
- **THEN** 面板可见时显示的是正文第一行，插入点在第一个字符之前

#### Scenario: 切换到另一条速记
- **WHEN** 面板可见，用户点击另一条速记的圆点
- **THEN** 编辑区显示那条速记的第一行，插入点在最开头
