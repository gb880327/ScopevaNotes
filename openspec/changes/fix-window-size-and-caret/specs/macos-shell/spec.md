## MODIFIED Requirements

### Requirement: 显示时定位与置顶

主窗口每次显示 MUST 恢复上次的窗口尺寸，该尺寸 MUST 跨进程重启持久化（保存到应用配置），MUST 按当前鼠标所在显示器居中并限制在可见区域内，MUST 在显示期间保持置顶，MUST 在隐藏时取消置顶。MUST NOT 保存或恢复主窗口坐标。

持久化的尺寸 MUST 在使用前做合法性收敛：小于最小尺寸（760×480）的值 MUST 提升到最小尺寸，超出当前显示器可见区域的值 MUST 收进可见区域，不得让窗口出现在屏幕外或不可缩放。

配置不可用（文件缺失、内容损坏、写入失败）时 MUST 回退到默认尺寸（1100×720）并继续工作，MUST NOT 阻断启动、显示或隐藏。速记面板的定位与尺寸规则由 `quick-tabs` capability 定义，MUST NOT 套用本条的中心定位规则。

#### Scenario: 鼠标在副屏
- **WHEN** 鼠标位于副显示器且用户唤出主窗口
- **THEN** 主窗口出现在该显示器中央而非主屏

#### Scenario: 显示器断开
- **WHEN** 上次使用的副屏被拔掉后再唤出主窗口
- **THEN** 主窗口出现在现存显示器可见范围内，不落在屏幕外

#### Scenario: 置顶仅在显示时生效
- **WHEN** 主窗口隐藏后用户切换到其他应用
- **THEN** 其他应用窗口正常获得焦点，不被隐藏窗口抢占

#### Scenario: 调整尺寸后重启仍是上次的尺寸
- **WHEN** 用户把主窗口拖到 1320×860，然后隐藏窗口并退出应用，再重新启动并唤出主窗口
- **THEN** 主窗口以 1320×860 显示，而不是默认的 1100×720

#### Scenario: 保存的尺寸比当前屏幕更大
- **WHEN** 用户在 2560 宽的显示器上把主窗口拉到 2000 宽后退出，随后在 1440 宽的显示器上启动并唤出主窗口
- **THEN** 主窗口被收进 1440 宽显示器的可见区域，四个边都在屏幕内

#### Scenario: 尺寸配置损坏不阻断启动
- **WHEN** 配置文件里的尺寸字段被改成非法内容或整个配置文件损坏
- **THEN** 应用以默认尺寸正常启动与显示，笔记数据不受影响
