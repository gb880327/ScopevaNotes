## MODIFIED Requirements

### Requirement: 显示时定位与置顶

主窗口每次显示 MUST 恢复上次的窗口尺寸，该尺寸 MUST 跨进程重启持久化（保存到应用配置），MUST 按当前鼠标所在显示器居中并限制在可见区域内，MUST 在显示期间保持置顶，MUST 在隐藏时取消置顶。MUST NOT 保存或恢复主窗口坐标。

持久化的尺寸 MUST 在使用前做合法性收敛：小于最小尺寸（760×480）的值 MUST 提升到最小尺寸，超出当前显示器可见区域的值 MUST 收进可见区域，不得让窗口出现在屏幕外或不可缩放。

配置不可用（文件缺失、内容损坏、写入失败）时 MUST 回退到默认尺寸（1100×720）并继续工作，MUST NOT 阻断启动、显示或隐藏。速记面板的定位与尺寸规则由 `quick-tabs` capability 定义，MUST NOT 套用本条的中心定位规则。

当其他应用正处于全屏（独立 Space）时唤出主窗口，主窗口 MUST 显示在该全屏应用之上，MUST NOT 留在用户原来的桌面或别的 Space，MUST NOT 让用户被动退出全屏。为此主窗口 MUST 是一个全屏辅助面板：窗口类 MUST 为 `NSPanel` 的子类，样式 MUST 含 `NSWindowStyleMaskNonactivatingPanel`，`collectionBehavior` MUST 含 `CanJoinAllSpaces | FullScreenAuxiliary`。仅给普通 `NSWindow` 设置 `collectionBehavior` MUST NOT 被视为满足本条。

该能力 MUST NOT 让主窗口退化为不接收键盘输入的浮层：窗口 MUST 能成为 key，且在成为 key 时 MUST 让本应用成为活动应用（菜单栏归属本应用），原生标题栏、红绿灯、关闭即隐藏（⌘W）与退出确认（⌘Q）语义 MUST 不变。

#### Scenario: 鼠标在副屏
- **WHEN** 鼠标位于副显示器且用户唤出主窗口
- **THEN** 主窗口出现在该显示器中央而非主屏

#### Scenario: 显示器断开
- **WHEN** 上次使用的副屏被拔掉后再唤出主窗口
- **THEN** 主窗口出现在现存显示器可见范围内，不落在屏幕外

#### Scenario: 置顶仅在显示时生效
- **WHEN** 主窗口隐藏后用户切换到其他应用
- **THEN** 其他应用窗口正常获得焦点，不被隐藏窗口抢占

#### Scenario: 调整尺寸后重启仍是上次的尺寸
- **WHEN** 用户把主窗口拖到 1320×860，然后隐藏窗口并退出应用，再重新启动并唤出主窗口
- **THEN** 主窗口以 1320×860 显示，而不是默认的 1100×720

#### Scenario: 保存的尺寸比当前屏幕更大
- **WHEN** 用户在 2560 宽的显示器上把主窗口拉到 2000 宽后退出，随后在 1440 宽的显示器上启动并唤出主窗口
- **THEN** 主窗口被收进 1440 宽显示器的可见区域，四个边都在屏幕内

#### Scenario: 尺寸配置损坏不阻断启动
- **WHEN** 配置文件里的尺寸字段被改成非法内容或整个配置文件损坏
- **THEN** 应用以默认尺寸正常启动与显示，笔记数据不受影响

#### Scenario: 全屏应用之上显示主窗口
- **WHEN** 用户把某个应用切到全屏，然后在菜单栏选择「显示主窗口」
- **THEN** 主窗口显示在该全屏应用之上并可直接输入，那个应用的全屏状态保持不变，用户不必先退出全屏或切 Space

#### Scenario: 焦点跟随菜单栏
- **WHEN** 其他应用在前台，用户点击角落里仍可见的主窗口
- **THEN** 主窗口获得键盘焦点，菜单栏切换为本应用的菜单

### Requirement: 菜单栏常驻

应用 MUST 提供菜单栏图标与菜单。图标左键 MUST 显示或隐藏速记面板，图标右键 MUST 打开应用菜单，两者 MUST 互不干扰（左键不弹菜单、右键不切面板）。菜单 MUST 至少包含：显示主窗口、新建笔记、导入 Markdown…、设置、开机启动开关、退出。菜单项 MUST 与界面内同名操作使用同一业务路径。

菜单 MUST NOT 出现与其他菜单项行为重复的入口。库的查看、路径切换与库信息 MUST 只经「设置」内的库分区提供，MUST NOT 单列一个只做同样事情的菜单项。

#### Scenario: 左键切换速记面板
- **WHEN** 用户点击菜单栏图标左键
- **THEN** 速记面板显示或隐藏，主窗口显隐状态不变

#### Scenario: 右键打开菜单
- **WHEN** 用户点击菜单栏图标右键
- **THEN** 应用菜单展开，速记面板不被切换

#### Scenario: 菜单显示主窗口
- **WHEN** 用户在菜单栏选择「显示主窗口」
- **THEN** 主窗口显示并获得焦点，速记面板保持原状态

#### Scenario: 菜单新建笔记
- **WHEN** 用户在菜单栏选择「新建笔记」
- **THEN** 主窗口显示并进入新建笔记的编辑状态，聚焦标题

#### Scenario: 菜单不出现重复的库入口
- **WHEN** 用户右键打开应用菜单
- **THEN** 菜单中没有「笔记库」一项，库的查看与切换只能经「设置」进入

#### Scenario: 菜单栏显示品牌标识
- **WHEN** 应用运行于菜单栏
- **THEN** 显示品牌 logo（蓝色圆角方块标记），高度约 18pt、按等比缩放，在深浅色菜单栏下都能辨认
