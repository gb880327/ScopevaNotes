## Context

仓库已有可运行的 Tauri 2 + Vue 3 + SQLite 骨架（提交 `f42ab93`、`1234a06`），产品范围与里程碑来自 `docs/macos-notes-manager-v1-implementation-plan.md`。本 change 将那份计划固化为规格，并决定实现期的技术取向。已落地的实现取舍见 `docs/DECISIONS.md`，架构分层见 `docs/ARCHITECTURE.md`；本文件不重复逐条细节，只记录会影响后续任务的设计决策。

约束：
- 仅 macOS 12+，Intel 与 Apple Silicon 都要能构建；不联网、无账号、无服务端。
- 单主窗口 + 菜单栏常驻形态决定了生命周期不能按「关窗即退出」实现。
- 数据是用户唯一资产，笔记库可被放到云同步目录，任何失败路径都不能静默丢数据。

## Goals / Non-Goals

**Goals:**
- 键盘优先：全局快捷键唤出 → 搜索/新建 → 编辑 → 自动保存，全程不需要鼠标。
- 数据可携带：单个 SQLite 文件，可备份、可换路径、可放同步盘。
- 行为可验收：每个能力都有可测试的规格与场景，测试计划与规格一一对应。

**Non-Goals:**
- 不做独立 Snippet 实体、快速面板、多窗口、第三栏（计划 §0 已排除）。
- 不做云同步服务、账号体系、协作编辑、移动端。
- 不做插件系统、主题市场、自定义 CSS。
- V1 不做加密库（笔记库不以加密为前提设计）。

## Decisions

**D1 单连接 + Mutex + `spawn_blocking`。** V1 数据量小且写入天然串行，单连接避免多连接写冲突与 WAL 调优；`spawn_blocking` 保证不阻塞 UI。备选：专用 DB 线程（消息队列）——并发上限更高，但需要额外请求/响应通道与取消语义，等搜索压测显示锁竞争再迁移。

**D2 迁移一版本一事务，拒绝降级。** `schema_migrations` 记录已应用版本；执行前比对程序支持的最大版本，磁盘更新则拒绝启动并提示升级应用。备选：自动向下兼容读取——会让新版字段在新库上被静默丢弃，风险更高。

**D3 乐观并发而非悲观锁。** 保存携带 `expectedUpdatedAt`，不匹配返回冲突。单用户桌面场景冲突极少，代价是冲突时必须给用户可见处理入口（当前 UI 呈现错误条，M6 任务补齐重载/覆盖选择）。

**D4 软删除。** `deleted_at` 非空即删除；所有列表/搜索/计数都过滤，FTS 投影同时移除。备选：物理删除 + 备份——恢复成本高，且误删是高频事故。

**D5 自动保存用防抖 + 串行队列 + 版本号。** 600ms 防抖降低写入频率，队列保证顺序，版本号防止旧响应覆盖新输入。备选：每次按键保存——写入放大且冲突窗口变长。

**D6 搜索先 LIKE，后接 FTS5。** 表与投影已建好并在写路径维护，M4 才把查询切到 `MATCH`（含中文单/双字回退与排序）。这样 M1–M3 不被分词问题阻塞，同时避免「先上 FTS 再补索引维护」导致的数据不一致窗口。

**D7 窗口显隐集中到 `WindowManager`。** 快捷键、菜单栏、IPC、关闭按钮都走同一入口，内部加锁串行化，`visible` 只在成功后更新。备选：各处自行 `window.show()`——已证明会产生状态漂移与焦点丢失。

**D8 每次显示重新居中，只持久化尺寸。** 用户在多显示器间移动时，「上次位置」经常落在已断开的屏幕上；居中到鼠标所在屏更可预测。备选：恢复坐标——多屏场景失败率高。

**D9 偏好与数据分离。** 主题/强调色/字号/栏宽写 Tauri Store，笔记库只有笔记与标签。好处：换库不丢外观、备份文件不含个人偏好；代价是偏好不随库迁移。

**D10 备份用 `VACUUM INTO` 且不覆盖。** 得到一致性快照，不依赖 WAL 文件；目标存在即失败，避免误覆盖用户已有备份。

**D11 前端只有 `services/commands.ts` 触碰 IPC。** 组件与 store 不直接 `invoke`，DTO 与错误在单一位置规范化，便于后续换传输或加日志。

## Risks / Trade-offs

- **FTS5 中文分词**：unicode61 对中文按字切分，双字以上查询可能过宽或过窄。缓解：M4 先做基准，必要时退回「FTS 粗筛 + LIKE 精筛」；规格已把「中文短词有结果」写成验收场景。
- **置顶窗口干扰**：显示期间 `always_on_top` 可能遮挡用户正在看的其他应用，尤其在 Spaces 切换时。缓解：隐藏即取消置顶；M0 实机验收必须覆盖 Spaces/全屏/Stage Manager。
- **关闭即隐藏的认知成本**：用户可能以为已退出。缓解：菜单栏常驻 + 首次引导说明；M6 任务补齐。
- **自动保存在强杀下丢最后一次输入**：当前只在 UI 操作路径 flush。缓解：接入退出钩子与窗口隐藏前 flush；验收场景已写入 `notes-core` 与 `release-readiness`。
- **云同步目录双写**：SQLite 文件被同步工具并发替换会损坏。缓解：规格要求可见错误与单设备提示，不做自动合并。
- **后台常驻资源**：WebView 常驻会有基础内存占用；缓解：隐藏时不跑轮询、不跑定时器，M7 做 24h 驻留测量。
- **单连接成为长任务瓶颈**：大库备份会占用连接。缓解：备份在 `spawn_blocking` 中执行，UI 显示 busy 状态；若影响交互再迁移到 D1 的备选方案。
