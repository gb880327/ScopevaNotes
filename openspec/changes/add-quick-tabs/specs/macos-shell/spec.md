## MODIFIED Requirements

### Requirement: 单主窗口

应用 MUST 只维护一个主笔记窗口，外加一个速记面板窗口（label `quick-tabs`，语义见 `quick-tabs` capability），MUST NOT 存在第三种窗口或窗口实例。主窗口默认尺寸 1100×720，最小尺寸 760×480，MUST 居中显示且 MUST 带原生窗口控制按钮。全局快捷键与界面内部操作 MUST 复用主窗口；菜单栏右键菜单与重复启动 MUST 唤出主窗口；菜单栏左键 MUST 只切换速记面板。速记面板的存在 MUST NOT 改变主窗口的尺寸、定位、置顶与显隐规则。

#### Scenario: 连按快捷键只有一个窗口
- **WHEN** 连续 100 次触发全局快捷键
- **THEN** 系统中始终只存在一个主窗口，无重复实例或残留幽灵窗口

#### Scenario: 速记面板不复制主窗口
- **WHEN** 用户连续 100 次点击菜单栏图标左键
- **THEN** 系统中始终只有一个速记面板实例，且主窗口显隐状态不变

#### Scenario: 尺寸受最小约束
- **WHEN** 用户把窗口缩小到极限
- **THEN** 宽高不低于 760×480，布局不出现内容溢出或控件不可达

### Requirement: 菜单栏常驻

应用 MUST 提供菜单栏图标与菜单。图标左键 MUST 显示或隐藏速记面板，图标右键 MUST 打开应用菜单，两者 MUST 互不干扰（左键不弹菜单、右键不切面板）。菜单 MUST 至少包含：显示主窗口、新建笔记、打开笔记库、设置、开机启动开关、退出。菜单项 MUST 与界面内同名操作使用同一业务路径。

#### Scenario: 左键切换速记面板
- **WHEN** 用户点击菜单栏图标左键
- **THEN** 速记面板显示或隐藏，主窗口显隐状态不变

#### Scenario: 右键打开菜单
- **WHEN** 用户点击菜单栏图标右键
- **THEN** 应用菜单展开，速记面板不被切换

#### Scenario: 菜单显示主窗口
- **WHEN** 用户在菜单栏选择「显示主窗口」
- **THEN** 主窗口显示并获得焦点，速记面板保持原状态

#### Scenario: 菜单新建笔记
- **WHEN** 用户在菜单栏选择「新建笔记」
- **THEN** 主窗口显示并进入新建笔记的编辑状态，聚焦标题

#### Scenario: 菜单栏显示品牌标识
- **WHEN** 应用运行于菜单栏
- **THEN** 显示品牌 logo（蓝色圆角方块标记），高度约 18pt、按等比缩放，在深浅色菜单栏下都能辨认

### Requirement: 退出确认

通过菜单栏「退出」、`Command+Q` 或系统退出动作请求退出时，系统 MUST 先刷新（flush）所有窗口的未保存编辑——包括主窗口当前笔记与速记面板当前速记——再显示确认对话框。用户取消 MUST 保持应用运行且窗口状态不变；确认后 MUST 结束进程。存在未保存内容或保存失败时 MUST 在对话框中说明，保存失败 MUST NOT 静默退出。速记面板 MUST NOT 自行弹出退出确认框，MUST 只响应主窗口发起的刷新请求。

#### Scenario: 取消退出
- **WHEN** 用户触发退出并在确认对话框中取消
- **THEN** 进程继续运行，窗口显隐状态与编辑内容保持原状

#### Scenario: 确认退出
- **WHEN** 用户触发退出并确认
- **THEN** 主窗口与速记面板的未保存编辑都已落盘，随后进程结束，菜单栏图标消失

#### Scenario: 未保存内容提示
- **WHEN** 存在未保存编辑时触发退出
- **THEN** 确认对话框说明仍有未保存内容；若保存失败则停留在对话框并提示错误，不结束进程

#### Scenario: 退出时只弹一次对话框
- **WHEN** 速记面板可见且用户按 `Command+Q`
- **THEN** 只出现一个退出确认对话框，两个窗口都不会重复请求退出

### Requirement: 显示时定位与置顶

主窗口每次显示 MUST 恢复上次的窗口尺寸、按当前鼠标所在显示器居中并限制在可见区域内，MUST 在显示期间保持置顶，MUST 在隐藏时取消置顶。MUST NOT 保存或恢复主窗口坐标。速记面板的定位与尺寸规则由 `quick-tabs` capability 定义，MUST NOT 套用本条的中心定位规则。

#### Scenario: 鼠标在副屏
- **WHEN** 鼠标位于副显示器且用户唤出主窗口
- **THEN** 主窗口出现在该显示器中央而非主屏

#### Scenario: 显示器断开
- **WHEN** 上次使用的副屏被拔掉后再唤出主窗口
- **THEN** 主窗口出现在现存显示器可见范围内，不落在屏幕外

#### Scenario: 置顶仅在显示时生效
- **WHEN** 主窗口隐藏后用户切换到其他应用
- **THEN** 其他应用窗口正常获得焦点，不被隐藏窗口抢占
