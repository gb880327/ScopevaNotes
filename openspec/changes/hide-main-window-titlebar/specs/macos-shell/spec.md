## ADDED Requirements

### Requirement: 主窗口无标题栏

主窗口 MUST NOT 显示系统标题栏：窗口标题文字 MUST 隐藏，标题栏底色 MUST 透明，内容 MUST 顶到窗口最上沿。窗口 MUST 保留原生窗口控制按钮（红/黄/绿）、系统圆角与阴影、双击缩放，以及关闭即隐藏、退出确认的既有语义；MUST NOT 改成无边框窗口或自绘标题栏。

窗口顶部 MUST 提供拖拽区，使窗口仍可被拖动。拖拽区 MUST 横跨窗口宽度，其左段宽度 MUST 与侧栏宽度一致、底色与侧栏一致并延续侧栏分隔线，右段底色与正文一致。内容 MUST NOT 被红绿灯遮挡。

拖拽 MUST 在窗口未处于前台时也生效：其他应用在前台时唤出主窗口，第一次按住拖拽区即可移动窗口，MUST NOT 要求先点一次把窗口激活。

#### Scenario: 主窗口没有标题栏
- **WHEN** 用户通过快捷键唤出主窗口
- **THEN** 窗口顶部没有标题文字与标题栏底色，侧栏与正文从窗口上沿开始，红绿灯浮在左上且不遮挡任何文字或控件

#### Scenario: 顶部拖拽
- **WHEN** 用户按住主窗口顶部那条空条拖动
- **THEN** 整个窗口跟随移动，位置仍按"显示时按鼠标所在显示器居中"的规则在下次唤出时重置

#### Scenario: 窗口未激活时的第一次拖拽
- **WHEN** 其他应用在前台时唤出主窗口，用户不做任何点击，直接按住顶部拖拽区拖动
- **THEN** 窗口立即跟随移动并同时成为前台应用，不需要先点一次再拖

#### Scenario: 窗口控制按钮仍可用
- **WHEN** 用户点击左上角红色按钮
- **THEN** 窗口隐藏而不退出进程；点击绿色按钮进入全屏、黄色按钮最小化，与改造前一致
